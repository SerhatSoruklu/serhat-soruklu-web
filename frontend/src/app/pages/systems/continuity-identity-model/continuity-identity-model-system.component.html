SYSTEM PURPOSE

What It Decides

CIM focuses on continuity under change. Its purpose is to evaluate whether a modified machine actor can still inherit authority that was previously granted.

The model is framed around changed machine actors, continuity, authority inheritance, and deterministic verification. It is a protocol workspace, not a deployed commercial product.

PROTOCOL AUTHORITY

Specification Before Implementation

The normative truth sources are CIM-SPEC-v0.1.md and packages/cim-core/vectors/. Implementations are conformance targets, not authorities.
